# Тестовый предмет для e2e

Не базовая программа. Предмет с главами, глоссарием, таблицей Менделеева и лентой времени — для e2e-тестов общих
блоков (`e2e/tests/subject-blocks.spec.ts`), когда «Химия» показывается модулем атласа (решение владельца 2026-10-28).

Загружается только вместе с `content/`: `pnpm db:seed --set=e2e` (в CI — после `--set=demo`). Обычный
`pnpm content:import` переводит тестовый предмет в архив.
