### Черновики «Наследия» (6 учёных)

- **Лавуазье.** Лавуазье сделал точное взвешивание правилом химии, а вместе с коллегами создал систему названий веществ (1787), которой химики пользуются до сих пор. Закон сохранения массы лежит в основе всех расчётов по уравнениям реакций.
- **Дальтон.** Атомная теория Дальтона стала основой химии XIX века: на ней построены атомные массы, химические формулы и, позже, периодическая система. В его честь единицу атомной массы называют дальтоном (Да), а цветовую слепоту — дальтонизмом.
- **Кюри.** Работы Марии Кюри положили начало радиохимии и лучевой терапии рака. Основанный ею Институт радия в Париже работает и сегодня как Институт Кюри, а элемент кюрий назван в честь Марии и Пьера Кюри.
- **Резерфорд.** Ядерная модель Резерфорда стала основой атомной физики: на неё опиралась модель Бора. В его лаборатории работали будущие нобелевские лауреаты (например, Джеймс Чедвик, открывший нейтрон), а элемент 104 назван резерфордием.
- **Бор.** Модель Бора объяснила линейчатые спектры атомов и связь электронных оболочек с периодической таблицей. Его институт в Копенгагене стал центром квантовой физики, а элемент 107 назван борием.
- **Полинг.** Идеи Полинга о химической связи и электроотрицательности вошли в каждый учебник химии. Его описание альфа-спирали белков стало важным шагом молекулярной биологии.

## 5. Формат в `content/` (предложение для S1b)

Новый файл темы `content/natural-sciences/01-chemistry/61-chemists/scientists.yaml` (рядом с `timeline.yaml`; проверяет `content:check`):

```yaml
scientists:
  - section: mendeleev            # код раздела урока
    born: { ru: Тобольск, kk: Тобыл, en: Tobolsk }
    country: { ru: Российская империя, kk: Ресей империясы, en: Russian Empire }
    field: { ru: Химия, kk: Химия, en: Chemistry }
    awards: { ru: 'Медаль Дэви (1882), медаль Копли (1905)', kk: '…', en: '…' }
    elements:                     # связанные элементы (номер и вид связи)
      - { number: 31, relation: predicted }
      - { number: 21, relation: predicted }
      - { number: 32, relation: predicted }
    sources:                      # дополнительно к «Источникам» урока
      - { title: Britannica, url: 'https://www.britannica.com/biography/Dmitri-Mendeleev' }
```

Виды связи — `discovered`, `predicted`, `named`, `structure` (подписи — в i18n на трёх языках). Годы жизни и главное открытие берутся из `timeline.yaml` — не дублируются. Формат будет описан в `docs/CONTENT_GUIDE.md` на этапе «Финал».
