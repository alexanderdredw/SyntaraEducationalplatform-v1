p95 API 24 мс. Главные проблемы:
1. **CLS 0,10–0,54 на 13 из 18 страниц** (цель ≤ 0,1): урок, каталог, «Показатели», «Достижения», профиль, редактор темы,
   аналитика — данные приходят из API в браузере после загрузки JS, контент вырастает и сдвигает футер; на главной — подмена шрифта Inter.
2. **LCP ≈ 3,0–3,4 с на Slow 4G и 6–6,7 с на Fast 3G на 8 страницах** (цель ≤ 2,5 с) — та же причина: главный текст появляется только после JS + запроса.
3. **≈ 100 КБ gzip лишнего JS на 47 из 48 страниц**: `@syntara/shared` собран в CommonJS, поэтому в браузер целиком попадают
   все схемы и полный Zod 4 со **всеми языковыми пакетами** (норвежский, финский, польский…) и компилятором JSON Schema.

Ожидаемый выигрыш после О4-1…О4-4: JS первой загрузки −60…120 КБ (≈ 20–30 %; гость и урок — к цели ≤ 300 КБ),
CLS ≤ 0,1, LCP урока и кабинетов на Slow 4G ≈ 1 с вместо 3,3 с. Оценка Performance урока 65 → ≥ 85.

Отдельно (не оптимизация, но важно): `pnpm audit --prod` — **1 критическая** уязвимость `next` ≤ 15.5.27 (RCE в Image Optimizer,
исправлено в 15.5.28) и 8 высоких (sharp, postcss, body-parser, multer) — см. 5.6 и решение О2-9.
