## 1. Источник и цель

**Источник:** отдельный сайт владельца «Молекулярный Атлас» в локальной папке владельца `…\Desktop\chemestry atlas` (путь передаётся в промпте). Сайт собран на основе анатомического атласа, поэтому в коде остались анатомические названия. Технически это Vanilla JS + three.js; данные лежат в `js/data/anatomy-data.js`, `js/data/glossary-data.js`, тексты — в `locales/ru_v2.json`, `kk_v3.json`, `en_v2.json`, картинки — в `assets/images/`.

Состав источника:

| Что | Объём |
|---|---|
| Элементы | 60 (водород … неодим). Поля: `atomicNumber`, `symbol`, `groupKey`, `color`, `image`. 5 слоёв: `atomic_structure`, `electron_shells`, `physical_properties`, `chemical_properties`, `applications`. Также `details`, `fact`, `resources` (Wikipedia, PubChem) и `ai` (simple, detailed, study, 5 вопросов с `correctIndex`) |
| Учёные | 9 (Менделеев, Кюри, Лавуазье, Бор, Резерфорд, Дальтон, Полинг, Нобель, Ходжкин), `groupKey: scientist`. Слои: `biography`, `discovery`, `impact`, `ai_bridge`. По 5 вопросов, портреты в `assets/images/scientists/` |
| Глоссарий | ≈ 146 терминов по разделам (`glossary.sect.*`, `glossary.term.*`, `glossary.def.*`) |
| Переводы | все ключи на RU, KK, EN; основные файлы — `ru_v2`, `kk_v3`, `en_v2`; файлы `*.backup*` и `*attempt` не использовать |

**Цель:** базовый предмет платформы «Химия» (`content/natural-sciences/01-chemistry/`, код `chemistry`; сейчас без тем, статус «Скоро») наполняется содержанием атласа. Всё оформляется в едином дизайне и формате платформы, с квизами, XP, прогрессом, заданиями, Syntara AI и тремя языками. Особые возможности атласа становятся **общими блоками платформы**, которые можно включить у любого предмета.

## 5. Перенос содержания (C2)

### REQ-CHEM-01. Конвертер
`scripts/content-import/atlas-chemistry.mjs`:
- путь к папке атласа передаётся аргументом (`--source <путь>`), в коде путь не прописывается;
- скрипт читает данные и тексты атласа, пишет файлы в `content/natural-sciences/01-chemistry/`;
- повторный запуск даёт тот же результат (идемпотентность);
- ручные исправления, утверждённые в C0, применяются через файл правок `scripts/content-import/atlas-chemistry.fixes.yaml`, а не правкой результата руками. Так конвертер можно перезапустить без потери исправлений.

- Глава «Химические элементы» (`elements`, position 1): 60 тем в порядке атомного номера. Код темы — английское имя элемента (`hydrogen`, …), position — порядковый номер в главе.
- Глава «Учёные-химики» (`scientists`, position 2): одна тема `chemists`, «Учёные-химики».
- Названия глав — RU, KK, EN (KK и EN — `needs_review`).
- `subject.yaml` предмета: название и описание не меняются; добавляются `chapters`.

## 6. Новые общие блоки

### 6.1 Главы предмета (C1) — BR-CHAP-01…05
1. В `subject.yaml` — необязательный список `chapters: [{ code, position, title: { ru, kk, en } }]`. В заголовке `ru.md` темы — необязательное `chapter: <код>`.
2. Если у предмета **есть** главы:
   - у каждой темы обязательно указана глава (иначе ошибка `content:check`);
   - `position` темы — порядок внутри главы;
   - «Тема N» нумеруется сквозь весь предмет.
   Если глав **нет**, всё работает как сейчас: «Анатомия человека» и остальные не меняются.
3. Страница предмета (ученик, гость, предпросмотр): темы сгруппированы по главам. Заголовок главы показывает «Освоено m из n» для ученика. Главы сворачиваются, по умолчанию развёрнута первая неосвоенная.
4. БД — только миграцией (новая таблица глав или поле у темы — решение Claude Code с обоснованием в отчёте); откат на чистой базе.
5. API страницы предмета расширяется **необязательным** полем `chapters`; старые клиенты и тесты не ломаются.
6. Предметы учителя в этой задаче глав **не получают**: `TODO(OWNER)` — нужны ли главы учителю.

### 6.2 Глоссарий предмета (C3) — REQ-GLOS-01…06
1. Файл `glossary.yaml` в папке предмета: разделы с терминами; `term` и `definition` на RU (обязательно), KK и EN (`needs_review`). Проверяется в `content:check`, импортируется вместе с предметом.
2. На странице предмета — вкладка или кнопка «Глоссарий» (только если у предмета есть глоссарий) → `/learn/subjects/:id/glossary`. Для гостя — та же возможность там, где ему доступен «Обзор» базовых уроков (BR-VIS-04).
3. Поиск по термину и определению без учёта регистра и «ё/е», с подсветкой совпадения; пустой результат — «Ничего не найдено».
4. Разделы как в источнике; внутри — по алфавиту языка интерфейса.
5. На телефоне 390 px — одна колонка, поле поиска закреплено сверху.
6. Хлебные крошки «Каталог / Химия / Глоссарий»; в панели активен «Каталог».

### 6.3 Таблица Менделеева (C4) — REQ-PTBL-01…08
1. На странице предмета «Химия», над главами: блок «Периодическая таблица». Включается полем в `subject.yaml` (например, `blocks: [periodic-table]`); у других предметов его нет.
2. Стандартная раскладка: 18 групп × 7 периодов + отдельные ряды лантаноидов и актиноидов, **все 118 элементов**. Справочные данные (номер, символ, название RU/KK/EN, группа) — в общем файле данных блока (не в коде компонентов), названия — через i18n.
3. Ячейка: номер, символ, название (на узкой ячейке — в подсказке). Цвет — по семейству элементов, из токенов `packages/ui`, в обеих темах. Цвет не единственный носитель смысла: есть легенда и `aria-label`.
4. Элемент с уроком — ссылка на урок. Элемент без урока — неактивная ячейка с подсказкой «Скоро».
5. Ученик видит на ячейке статус темы (освоена, в процессе), из уже существующих статусов тем, без новых правил подсчёта.
6. Фильтр-легенда: нажатие на семейство подсвечивает его элементы.
7. Клавиатура: роль `grid`, стрелки перемещают фокус, Enter открывает урок; видимый фокус. Экранный диктор: «Кислород, O, номер 8, неметалл, освоено».
8. Телефон: таблица прокручивается по горизонтали **внутри блока** (страница горизонтально не прокручивается), плюс переключатель «Списком». В «Экономии трафика» и при `prefers-reduced-motion` — без анимаций. Бюджет JS страницы ≤ 500 КБ; блок загружается динамически.

### 6.4 Лента времени (C5) — REQ-TL-01…05
1. Файл `timeline.yaml` в папке темы: события `{ year, title{ru,kk,en}, section: <код раздела> }`. Годы — **реальные** (рождение, ключевое открытие), а не `atomicNumber`, как в атласе. Годы проверить и привести в C0.
2. Блок показывается в уроке над разделами, если у темы есть `timeline.yaml`. Блок общий: подойдёт истории, физике и т. д.
3. Компьютер — горизонтальная шкала с точками; телефон — вертикальный список.
4. Нажатие на точку раскрывает и прокручивает к разделу учёного.
5. Доступность: список с кнопками, видимый фокус, без анимаций в «Экономии трафика».
