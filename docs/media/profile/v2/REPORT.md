## Вопросы владельцу

1. **«Требуют внимания» — причина «тема ниже 50 %».** API-T-25 отдаёт по ученикам только неактивность, поэтому сейчас причина одна: «не занимался N дней» или «ещё не занимался». Добавлять ли причину по результату темы?
2. **Письма о новом устройстве ученикам.** Сейчас письмо получают только учителя с подтверждённым email (BR-PRF-20). Нужно ли оно ученикам с email?
3. **Статусы копии данных.** Готовность копии не отслеживается, поэтому показывается «Запрос принят {дата}». «Копия данных готовится» и «Готово — скачать (ссылка действует 7 дней)» появятся вместе с выгрузкой копии.
4. **Картинки бейджей.** Медали из эталона U10 не предоставлены, пока у каждого бейджа своя иконка и цвет.
5. **Тексты не из ТЗ.** Около 90 новых строк записаны в `packages/shared/i18n/needs_confirmation.json`: подписи, подсказки для экранного диктора, тексты подтверждений. Например, «Выйти на устройстве «{device}»?» и «вчера, {time}». Казахские тексты добавлены в `needs_review.json` для проверки носителем.
