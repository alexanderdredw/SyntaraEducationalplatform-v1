## 2. Схема адресов

Один набор адресов для ученика, гостя и учителя: гость уже работает в `/learn/...` (SPEC 4, BR-VIS-04). Префикс языка `/{locale}` как у всей платформы. `:id` — ID предмета «Химия», `:code` — код темы-элемента (`oxygen`) или код раздела учёного (`mendeleev`).

| Адрес | Экран | Гость | Ученик | Учитель |
|---|---|---|---|---|
| `/learn/subjects/:id` | Главная | да | да | предпросмотр |
| `/learn/subjects/:id/explore` | Explore, карточки. Фильтр — `?group=halogen`, вид — `?view=table` | да | да, со статусами | предпросмотр |
| `/learn/subjects/:id/explore/:code` | Окно элемента поверх Explore | да | да; открытие = `lesson_opened` | предпросмотр |
| `/learn/subjects/:id/explore/:code/test` | Тест элемента (5 вопросов) | вход | да | предпросмотр без записи [А-9] |
| `/learn/subjects/:id/scientists` | Учёные | да | да | предпросмотр |
| `/learn/subjects/:id/scientists/:code` | Окно учёного поверх «Учёных» | да | да | предпросмотр |
| `/learn/subjects/:id/scientists/test` | Тест урока «Учёные-химики» (13 вопросов) [А-5] | вход | да | предпросмотр без записи |
| `/learn/subjects/:id/quiz` | Квиз «Проверь знания» | вход | да | предпросмотр без XP |
| `/learn/subjects/:id/search` | Поиск, запрос — `?q=` | да | да | да |
| `/learn/subjects/:id/glossary` | Глоссарий (адрес уже есть; термин — `#<код термина>`) | да | да | да |
| `/learn/subjects/:id/ai` | Syntara AI; контекст элемента — `?element=:code` | вход | да | предпросмотр |

Правила:
- Окна элемента и учёного — отдельные адреса. «Назад» и «×» закрывают окно и возвращают в Explore с тем же фильтром и прокруткой. Прямой заход и обновление страницы показывают окно поверх своего экрана (SSR).
- `code` → ID темы на сервере. В ответ API-S-18 и API-PUB-12 нужно добавить `code` темы — необязательное поле, старые клиенты не ломаются.
- Неизвестный `code` → 404 платформы.
- Предметы без `module: atlas-chemistry` по этим адресам не отвечают (404), их страница `/learn/subjects/:id` не меняется.

**Перенаправления старых адресов химии (308, на сервере):**

| Было | Станет |
|---|---|
| `/learn/topics/<тема-элемент>` (`?tab=overview`) | `/learn/subjects/:id/explore/<code>` |
| `/learn/topics/<тема-элемент>?tab=quiz[&assignment=X]` | `/learn/subjects/:id/explore/<code>/test[?assignment=X]` — так открываются задания учителя (`student-assignments.tsx`, `my-class.tsx`) |
| `/learn/topics/<тема-элемент>?tab=ai` | `/learn/subjects/:id/ai?element=<code>` |
| `/learn/topics/<chemists>` (`?tab=overview`) | `/learn/subjects/:id/scientists` |
| `/learn/topics/<chemists>?tab=quiz[&assignment=X]` | `/learn/subjects/:id/scientists/test[?assignment=X]` |
| `/learn/topics/<chemists>?tab=ai` | `/learn/subjects/:id/ai` |
| `/learn/subjects/:id/glossary` | Не меняется: на этом адресе будет глоссарий атласа |

Перенаправлять, только если предмет темы включает модуль атласа. Прочие темы и предметы не затрагиваются (AC-ATL-09).

## 5. Технические наблюдения

- **Стили.** Около 6 тыс. строк CSS в 11 файлах и встроенных `<style>`: глобальные селекторы (`body`, `.btn`, `.tag`, `.close-btn`, `.section-title`), много `!important` и встроенных стилей в JS. Изоляция (REQ-ATL-01.3): всё под корневым классом модуля (`.atlas-root`), `body.theme-light` → `.atlas-root[data-theme=light]`, переменные `--bg-primary` и др. — на корне модуля. Окна и шторки рендерятся в портал внутри того же корня.
- **Шрифты.** Inter (интерфейс) и Space Grotesk (заголовки, карточки) с Google Fonts. **У Space Grotesk нет кириллицы**: в RU и KK заголовки на деле рисуются запасным шрифтом стека (`'Space Grotesk', 'Inter', …` → Inter), латиница и цифры — Space Grotesk. Чтобы совпасть с эталоном, нужен тот же стек. Inter в платформе уже локальный (`apps/web/app/fonts.ts`); Space Grotesk — добавить локально (`next/font/local`, набор latin + latin-ext).
- `css/animations.css` подключён, но в папке его нет (404) — на вид не влияет, не переносим.
- `index.html` подключает `AnatomyViewer.js`, `Particles.js` и т. п., а файлы названы строчными буквами. На Windows это работает, на Linux — 404. Для эталона сервер искал файлы без учёта регистра.
- three.js и `OrbitControls`/`GLTFLoader` грузятся с CDN, но на экранах не используются (моделей нет).
- `prefers-reduced-motion` в оригинале не учитывается; частицы рисуются постоянно, даже на скрытых разделах (два canvas: Главная и «О нас»).
- В браузере 0 ошибок JS; одна ошибка загрузки — `animations.css`.
- Переменные `--primary`, `--primary-glow`, `--surface`, `--border` используются в квизе, но нигде не заданы: у круга с % на экране результата нет рамки и свечения, у мини-карточек «Рекомендуется повторить» нет фона и рамки (`quiz-result-*.webp`). Переносим как видно на эталоне (решение «визуально идентично»).
- Доступность оригинала: карточки, точки ленты, строка фильтра, пункты панели — `div` с обработчиком клика (не доступны с клавиатуры); у «×» и окна нет подписей; нет Esc и удержания фокуса; язык страницы меняется только скриптом.
- Объём оригинала без картинок и CDN: свой JS и CSS — 0,57 МБ; данные и переводы (`anatomy-data.js` + 3 файла переводов) — 2,9 МБ, грузятся целиком на любом экране. В платформе данные приходят с сервера по экрану, код экранов — отдельными чанками (REQ-ATL-06.3).

## 7. XP квиза «Проверь знания»: предложение

Подходящего правила нет: BR-XP-01 даёт XP только за квиз темы (`quiz_finished`) и первое открытие урока. Квиз атласа не связан с одной темой, поэтому `quiz_finished` не подходит.

**Предложение (вариант А, рекомендую):**
- Новое событие `atlas_quiz_finished` и `reason = 'atlas_quiz'` в `xp_ledger`.
- XP = число верных ответов (0–10) за завершённый квиз.
- Не больше **20 XP в день** с этого источника (2 полных квиза) — против «накрутки».
- Идемпотентно по ID сессии (BR-XP-02).
- Сессию создаёт сервер: 10 случайных элементов, сложность, тексты с «___». Ответ проверяет сервер, правильный вариант не уходит в браузер заранее (BR-QZ-01).
- Освоение тем, задания и бейджи «по квизам» не затрагиваются. В серию дней (BR-ST-02) событие идёт — как `quiz_finished` [А-11].
- Нужны миграция (таблица сессий, новое значение в `CHECK` типа события) и 3 эндпоинта: создать сессию, ответить, завершить — с тестами прав. Это полный режим, этап A4.

**Вариант Б (проще):** +10 XP за завершённый квиз с результатом ≥ 80%, не чаще одного раза в день. Без «за каждый ответ».

Числа (20 в день, 10 за квиз) — предложение, нужно утверждение [А-11].
