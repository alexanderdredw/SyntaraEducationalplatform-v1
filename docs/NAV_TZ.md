## 0. Концепция (решение владельца)

- **Гостевой режим — «обложка» проекта.** Он знакомит с платформой: главная, о проекте, предметы, Syntara AI, школам, помощь.
- **Авторизованный аккаунт — основная рабочая среда.** В нём доступно **всё**, что доступно гостю, **плюс** функции роли.
- **Пользователю никогда не нужно выходить из аккаунта**, чтобы открыть какую-либо страницу или функцию сайта. Выход требуется только для смены пользователя.
- После входа вся навигация собрана в **одной панели навигации** (слева на компьютере, в меню-панели на телефоне).

## Часть A. Единая панель навигации и доступ ко всем страницам

### A1. Текущее состояние (по скриншотам владельца и коду)
1. В хедере вошедшего нет публичного меню. На страницы «обложки» можно попасть только через футер.
2. Боковая панель на разных страницах разная. На странице «Предметы» в неё вперемешку попали публичные страницы без подписей, и есть две одинаковые иконки Syntara AI. На странице урока ~15 иконок с повторами (дом ×2, книга ×4, планшет ×2) и стрелка «←»: похоже, склеились несколько меню.
3. Иконки без подписей — при 10+ пунктах их невозможно различить.
4. Конфигурация пунктов — `apps/web/components/cabinet/nav.ts` (`CABINET_NAV`), панель — `cabinet-sidebar.tsx`, публичное меню — `components/shell/nav-items.ts`. Перед правками найти, откуда на скриншотах берутся лишние и повторяющиеся пункты (в том числе незакоммиченные изменения или отдельные меню страниц урока), и описать причину в отчёте.

### A2. Требования

**REQ-NAV-01. Один источник пунктов.**
Все пункты панели задаются в одном конфиге (`nav.ts`): для каждой роли — группы и пункты (ключ i18n, адрес, иконка, правило активности). Панель рендерится один раз в общей оболочке. Ни одна страница (урок, квиз, Battle, публичные) не добавляет свои пункты в панель.

**REQ-NAV-02. Состав панели.**

*Ученик:*
| Группа | Пункты (порядок) |
|---|---|
| — (сверху) | Главная `/` |
| **Мой кабинет** | Предметы `/learn/subjects` · Мои задания `/learn/assignments` · Syntara AI `/learn/assistant` · Battle `/learn/battles` · Показатели `/learn/progress` · Достижения `/learn/achievements` |
| **Платформа** | О проекте `/about` · Школам `/schools` |
| — (внизу) | Помощь `/support` |

У ученика нет отдельных пунктов «Предметы платформы» (`/subjects`) и публичного «Syntara AI» (`/ai`): их функции полностью покрывают «Предметы» и «Syntara AI» кабинета. Сами страницы остаются доступными по ссылкам (REQ-NAV-04).

*Учитель:*
| Группа | Пункты (порядок) |
|---|---|
| — (сверху) | Главная `/` |
| **Мой кабинет** | Мои курсы `/teacher/courses` · Классы `/teacher/classes` · Задания `/teacher/assignments` · Battle `/teacher/battles` |
| **Платформа** | Предметы платформы `/subjects` · Syntara AI `/ai` · О проекте `/about` · Школам `/schools` |
| — (внизу) | Помощь `/support` |

Служебные роли (поддержка) — без изменений в рамках этой задачи.

**REQ-NAV-03. Вид панели (компьютер, ≥ 768 px).**
1. Каждый пункт: иконка + **подпись**. Ширина развёрнутой панели ≈ 220 px.
2. Группы разделены тонкой линией и подписаны мелким капслоком («МОЙ КАБИНЕТ», «ПЛАТФОРМА»).
3. Кнопка «Свернуть панель» внизу: свёрнутое состояние — узкая полоса из иконок (~70 px, как сейчас), у иконок подсказки (`title`, `aria-label`), подписи групп скрыты, разделители остаются. Выбор «свёрнуто/развёрнуто» запоминается на устройстве (`localStorage`, обёрнутый в try/catch).
4. Иконки уникальны: два пункта не могут иметь одинаковую иконку. Предложенные: Главная — дом; Предметы/Мои курсы — книга; Задания — планшет; Syntara AI — искры; Battle — молния; Показатели — график; Достижения — кубок; Классы — люди; Предметы платформы — сетка/библиотека; О проекте — «i» в круге; Школам — здание; Помощь — спасательный круг.
5. Активный пункт — как сейчас: синяя подложка и полоса слева, `aria-current="page"`. Для страниц внутри раздела (тема — внутри «Предметы», сессия Battle — внутри «Battle») активен родительский пункт.
6. Без стрелки «←» и без пунктов урока: навигация внутри урока — хлебные крошки (уже есть).

**REQ-NAV-04. Ничего не исчезает после входа.**
1. Все страницы, доступные гостю (`/`, `/subjects`, `/learn/sections/:id`, `/learn/subjects/:id`, `/learn/topics/:id` для базовых уроков, `/about`, `/ai`, `/schools`, `/schools/request`, `/support`, `/terms`, `/privacy`, `/cookies`), открываются для вошедшего ученика и учителя **без выхода из аккаунта** и **без переадресации на вход**.
2. Вошедший пользователь видит эти страницы **внутри рабочей среды**: хедер кабинета (серия и XP у ученика, роль, язык, трафик, тема, уведомления, профиль, «Выйти») и панель навигации. Контент страницы — тот же, что у гостя, кроме REQ-NAV-05.
3. Формы гостевого режима работают для вошедшего: заявка школы, обращение в поддержку, пробный вопрос на главной.
4. Исключения — только страницы входа, которые вошедшему не нужны: `/auth/login`, `/auth/start`, «Как продолжить?», «Забыли пароль?» — для вошедшего переадресация на главную его роли. `/join` для вошедшего ученика — вступление в класс по коду (как сейчас).

**REQ-NAV-05. Кнопки «обложки» для вошедшего.**
На публичных страницах кнопки, рассчитанные на гостя («Войти», «Начать», «Начать бесплатно», «Зарегистрироваться», «Заниматься без аккаунта»), для вошедшего заменяются:
- у ученика — на «Продолжить учёбу →» (последняя открытая тема, иначе `/learn/subjects`), как в REQ-ST-HOME-01;
- у учителя — на «Перейти в кабинет →» (`/teacher/courses`).
Кнопка «Войти» в хедере у вошедшего не показывается нигде.

**REQ-NAV-06. Логотип.**
Логотип «Syntara» ведёт на главную роли: у ученика — `/` (его главная с «Продолжить учёбу»), у учителя — `/teacher/courses`.

**REQ-NAV-07. Телефон (< 768 px).**
Меню-панель UX-10 для вошедшего содержит блоки в порядке: «Мой кабинет» (с «Главной» сверху), «Платформа», «Помощь», «Язык», «Настройки». Горизонтальная строка иконок под хедером (текущее мобильное поведение панели) заменяется этим меню. Все требования UX-10 к доступности и закрытию меню сохраняются.

**REQ-NAV-08. Тексты.** Подписи пунктов и групп — через i18n (RU/KK/EN), новые — в `needs_confirmation.json`, KK/EN — `needs_review`.

### A3. Критерии приёмки (часть A)
| ID | Проверка |
|---|---|
| AC-NAV-01 | Панель одинакова на всех страницах роли: «Предметы», урок (все вкладки), квиз, Battle, «О проекте», главная — сравнение списка пунктов в e2e |
| AC-NAV-02 | В панели нет повторяющихся пунктов и повторяющихся иконок, нет «←» |
| AC-NAV-03 | Для каждой гостевой страницы из REQ-NAV-04 вошедшие ученик и учитель получают 200, остаются в аккаунте (хедер кабинета, панель) — e2e проходит список маршрутов для обеих ролей |
| AC-NAV-04 | Заявка школы, обращение в поддержку и пробный вопрос работают у вошедшего |
| AC-NAV-05 | На публичных страницах у вошедшего нет «Войти»/«Зарегистрироваться»; вместо них — «Продолжить учёбу» / «Перейти в кабинет» |
| AC-NAV-06 | Свёрнутая и развёрнутая панель работают; состояние запоминается; подписи видны в развёрнутой, подсказки — в свёрнутой |
| AC-NAV-07 | Телефон 320/390 px: меню содержит «Мой кабинет» и «Платформа»; нет горизонтальной прокрутки |
| AC-NAV-08 | Клавиатура, экранный диктор (`nav` с `aria-label`, `aria-current`), axe без нарушений, обе темы |
| AC-NAV-09 | Гость видит прежнюю шапку и меню «обложки» без изменений |
