## 1. Текущее состояние (скриншоты владельца)
1. Кнопка «+ Добавить тему» сразу создаёт черновик «Новая тема». Ненужные черновики («Тема 1 — Новая тема», «Тема 2 — Новая тема») удалить нельзя, они копятся в списке тем предмета.
2. Галерея обложек («Обложка темы») хранит все загруженные картинки учителя. Удалить ненужные нельзя. Пять картинок висят в статусе «Проверяется» (см. п. 5).
3. Материалы урока уже удаляются кнопкой «✕» — проверить, что при этом удаляется и файл в хранилище.

## 2. Удаление черновика темы

**BR-DEL-01. Что можно удалить.**
Учитель может удалить **свою** тему, только если она **никогда не публиковалась**: нет ни одной опубликованной версии и `published_version_id` пуст.

Нельзя удалить:
- опубликованную тему или когда-либо публиковавшуюся (даже снятую с публикации) → 409 `topicHasHistory`, текст: «Эту тему уже видели ученики — её можно снять с публикации, но не удалить, чтобы сохранить их результаты»;
- тему, на которую есть задание (`assignments`) → 409 `topicHasAssignments`;
- тему базовой программы платформы (как сейчас — 404).

**BR-DEL-02. Что удаляется вместе с черновиком.**
Переводы темы, квиз, вопросы, варианты, материалы темы (записи + объекты в хранилище — через задачу worker), черновые версии, разделы. Обложки из галереи **не удаляются** (они принадлежат галерее учителя). Запись в журнал аудита (кто, когда, название темы).
Удаление — в одной транзакции; объекты хранилища удаляются после фиксации транзакции (через outbox/worker), повторное удаление объекта безопасно.

**BR-DEL-03. Порядок тем.**
После удаления «Тема N» у оставшихся тем пересчитывается без пропусков, порядок не меняется.

**API-T-30.** `DELETE /api/teacher/topics/:id` → 204; ошибки из BR-DEL-01; чужая тема → 404; CSRF.

**Интерфейс:**
1. Страница предмета, список «Темы»: у **черновиков, которые можно удалить**, справа от статуса — кнопка-иконка «корзина» (`aria-label` «Удалить черновик «{название}»»). У остальных тем кнопки нет.
2. Редактор темы, внизу (рядом с «Сохранить»): текстовая кнопка «Удалить черновик» (опасное действие, красный текст), только для удаляемых тем.
3. Перед удалением — окно подтверждения: «Удалить тему «{название}»? Текст, квиз и материалы будут удалены без возможности восстановления.» Кнопки «Удалить» (красная) и «Отмена». Фокус по умолчанию — на «Отмена».
4. После удаления из редактора — переход на страницу предмета и уведомление «Черновик удалён».

## 3. Удаление изображений из галереи

**BR-DEL-04. Что можно удалить.**
Учитель может удалить **свою** картинку из галереи (`media_files.kind = 'cover'`, владелец — он), в любом статусе («Проверяется», «Готов», «Отклонён»).

Нельзя удалить картинку, которая:
- выбрана обложкой в текущем черновике какой-либо его темы, или
- используется в опубликованной версии темы.

В этом случае → 409 `coverInUse`, текст: «Эта картинка — обложка темы «{название}». Сначала выберите для темы другую обложку или уберите её.»

**BR-DEL-05. Как удаляется.**
Запись удаляется (или помечается удалённой — по принятому в проекте способу), объект в хранилище удаляется задачей worker. Если картинка ещё проверяется антивирусом, задача проверки после удаления завершается без ошибки. Запись в журнал аудита.

**API-T-31.** `DELETE /api/teacher/gallery/:mediaId` → 204; ошибки из BR-DEL-04; чужая картинка → 404; CSRF.

**Интерфейс:**
1. У каждой миниатюры галереи — кнопка «✕» в углу: на компьютере видна при наведении и при фокусе с клавиатуры, на телефоне видна всегда. `aria-label` «Удалить изображение».
2. Подтверждение: «Удалить изображение из галереи?» → «Удалить» / «Отмена».
3. У картинки, которая используется (BR-DEL-04), кнопка «✕» неактивна, с подсказкой «Используется как обложка темы «…»».
4. Рядом с выбранной обложкой в редакторе — кнопка «Убрать обложку» (тема без обложки), если такой кнопки ещё нет.

## 4. Материалы урока
Проверить, что «✕» у материала удаляет запись и объект в хранилище (через worker) и что удалённый материал больше не выдаётся ученикам. Если что-то из этого не так — исправить.

## 5. Ошибка: картинки висят в статусе «Проверяется»
На скриншоте 5 обложек давно в статусе «Проверяется». Найти причину (worker `file-scan`, ClamAV, очередь, проверка картинок), исправить и описать в отчёте. Если ClamAV локально ещё загружает базы — проверка должна завершиться сама после его готовности (повтор задачи), без ручных действий.

## 6. Критерии приёмки
| ID | Проверка |
|---|---|
| AC-DEL-01 | Черновик, ни разу не публиковавшийся, удаляется со страницы предмета и из редактора после подтверждения |
| AC-DEL-02 | Опубликованная и снятая с публикации тема не удаляется (кнопки нет; API — 409 `topicHasHistory`) |
| AC-DEL-03 | Тема с заданием не удаляется (409 `topicHasAssignments`) |
| AC-DEL-04 | После удаления черновика его квиз, вопросы, материалы удалены, объекты в хранилище удалены; нумерация тем без пропусков |
| AC-DEL-05 | Картинка галереи удаляется после подтверждения; объект в хранилище удалён |
| AC-DEL-06 | Используемая обложка не удаляется (409 `coverInUse`, кнопка неактивна с подсказкой) |
| AC-DEL-07 | Чужой учитель не может удалить тему или картинку (404) |
| AC-DEL-08 | «Убрать обложку» работает; тема без обложки показывается ученику без пустого места |
| AC-DEL-09 | Картинки не зависают в «Проверяется»: после проверки — «Готов» или «Отклонён» |
| AC-DEL-10 | Клавиатура, экранный диктор, axe, телефон 390 px, обе темы; тексты через i18n (RU/KK/EN, `needs_confirmation.json`) |

## 7. Ограничения
- Ничего, что видели ученики, не удаляется: результаты, попытки, опубликованные версии сохраняются.
- Логику публикации, квизов, заданий не менять.
- Только компоненты `packages/ui`; React Bits не подключать.
- Промежуточные коммиты + push; «Текущее состояние» в PLAN.
