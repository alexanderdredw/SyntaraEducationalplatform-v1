## 1. Текущее состояние
По `CHEM_TZ.md` (C1–C6) содержание атласа разложено по стандартным страницам платформы:
- страница предмета с главами и таблицей Менделеева;
- урок-аккордеон, схемы Бора вместо картинок атласа;
- лента и глоссарий в стиле платформы.

Содержание при этом исправлено (CHEM_MAP: ответы тестов, факты, переводы, 21 новый факт) и импортировано: 60 тем элементов + «Учёные-химики».

## 2. Проблема
Владелец ожидал **перенос самого сайта**: каждая страница атласа должна выглядеть и работать как в оригинале — расположение, карточки, навигация, анимации, эффекты. Текущая реализация — новая структура и другой дизайн.

## 3. Решения владельца (2026-10-27)
**Принцип.** Раздел «Химия» визуально идентичен оригинальному сайту «Mendeleev Atlas». Техническая часть адаптируется и улучшается: интеграция с платформой, архитектура, скорость, стабильность, безопасность. Изменения вида допускаются **только** там, где этого требует интеграция (шапка, вход, язык, тема, данные платформы).

| № | Решение |
|---|---|
| 1 | Сверху — шапка платформы (вход, XP, язык, тема). Под ней — навигация-«таблетка» атласа. Своя шапка атласа (логотип, кнопка темы, кнопка языка «EN») не показывается: эти функции выполняет шапка платформы. Левая панель платформы остаётся |
| 2 | Логотип «MENDELEEV ATLAS» (значок + надпись, как в оригинале) — слева от «таблетки» |
| 3 | Таблица Менделеева — **дополнительный вид в Explore** (переключатель «Карточки / Таблица»), оформленный в стиле атласа. По умолчанию — карточки, как в оригинале |
| 4 | В карточке (окне) элемента — кнопка **«Пройти тест»** в стиле атласа: тест темы платформы (5 вопросов), XP, прогресс, задания учителя |
| 5 | Квиз «Проверь знания» (10 вопросов «узнай элемент») — как в оригинале **и с начислением XP** |
| 6 | Раздел «Статистика» (Analytics) — **убрать** (есть «Показатели» платформы) |
| 7 | Раздел «О проекте» (About) с фото команды — **убрать** |
| 8 | Портреты учёных — проверенные версии с Wikimedia Commons (общественное достояние, CHEM_MAP 5.3), включая замену для Полинга; Ходжкин — без фото, с инициалами в стиле карточки атласа |
| 9 | Картинки атомов — **оригинальные картинки атласа для всех 60 элементов**, включая 11 с ошибками, до их перегенерации владельцем (список нужен в отчёте) |
| 10 | Содержание — **исправленное** (CHEM_MAP, решения C0 и итога C6), а не тексты оригинала |

**Итог: 7 разделов «таблетки»** — Главная (Home), Explore, Учёные (Scientists), Квиз (Quiz), Поиск (Search), Глоссарий (Glossary), Syntara AI. Плюс окна элемента и учёного.

**Исключение из правил платформы (записать в SPEC и CLAUDE.md):** модуль атласа использует собственный визуальный стиль (стили, шрифты, эффекты оригинала) в изолированной области. Правило «только токены и компоненты `packages/ui`» на него не распространяется. Остальные правила (права на сервере, i18n, доступность, бюджеты, миграции, безопасность) действуют полностью.

Оригинал — локальная папка владельца `…\Desktop\chemestry atlas` (путь передаётся в промпте; только чтение, не копировать в репозиторий целиком, путь в репозиторий не записывать).

## 5. Требования

### REQ-ATL-01. Модуль и адреса
1. Вход в «Химию» из каталога ведёт на «Главную» атласа. У каждого раздела и окна — свой адрес, чтобы работали «назад», ссылки, обновление страницы и задания учителя. Например:
   - `/learn/subjects/:id` — Главная;
   - `…/explore`, `…/explore/:elementCode` — окно элемента;
   - `…/scientists`, `…/scientists/:code`;
   - `…/quiz`, `…/search`, `…/glossary`, `…/ai`.

   Для гостя — такой же набор в гостевых адресах там, где ему доступен базовый контент (BR-VIS-04). Окончательную схему адресов показать в A0.
2. Старые адреса химии (страница темы-урока, глоссарий и лента платформы) — постоянное перенаправление на соответствующий экран атласа.
3. Код модуля — отдельная папка, например `apps/web/components/subjects/atlas-chemistry/`. Стили изолированы (CSS Modules или единый корневой класс): ни одно правило не влияет на остальную платформу, и наоборот.
4. Модуль включается полем предмета (например, `module: atlas-chemistry` в `subject.yaml`). Остальные предметы работают по-прежнему.

### REQ-ATL-02. Оболочка
1. Шапка и левая панель платформы — без изменений. В панели активен «Каталог».
2. Под шапкой — полоса атласа: логотип «MENDELEEV ATLAS» и «таблетка» из 7 разделов. Активный раздел выделен, как в оригинале.
3. Тема: переключатель платформы включает тёмную или светлую тему атласа (обе темы оригинала переносятся).
4. Язык: переключатель платформы (RU, KK, EN). Плавающая кнопка языка атласа «EN» не показывается.
5. Телефон: под шапкой платформы — мобильная полоса атласа, как в оригинале (кнопка меню + логотип). Меню атласа открывается, как в оригинале. Конфликт с плавающими кнопками платформы («?», чат) исключён.

### REQ-ATL-04. Данные
1. Источник правды — `content/` (исправленное содержание). Поля, которых не хватает экранам атласа, добавляются в формат `content/`, проверяются в `content:check` и импортируются. Например:
   - короткое описание для карточки;
   - группа и цвет;
   - чипы слоёв;
   - цитата учёного;
   - портрет.
2. Конвертер `atlas-chemistry.mjs` дополняется этими полями; повторный запуск идемпотентен; файл правок сохраняется.
3. Схемы Бора: из уроков химии убрать. Скрипт и SVG можно оставить в `scripts/content-art/`, если они не мешают проверкам.
4. Тексты интерфейса атласа (кнопки, заголовки экранов) — в i18n платформы на RU/KK/EN, взятые из переводов атласа; KK и EN — `needs_review`.

### REQ-ATL-05. Картинки
1. Атомы — оригиналы атласа для всех 60 элементов (если есть `_luxury` и `_lux` — брать ту, что показывает оригинал). WebP, ≤ 300 КБ. Размер — достаточный для чёткости в окне элемента; если в 300 КБ не укладывается — доложить. `license: own`, источник «Mendeleev Atlas, собственная работа владельца (сгенерировано ИИ)».
2. В отчёте — список 11 картинок с ошибками (элемент, что не так) для перегенерации и описание, как заменить файл после перегенерации (путь, команда импорта).
3. Портреты — решение 8 (источник и лицензия в `media`).
4. Ленивая загрузка, правильные размеры (`sizes`), без сдвигов вёрстки.

### REQ-ATL-06. Техническое качество
1. Без внешних CDN; шрифты атласа — локально (`next/font`) или системные, если так в оригинале.
2. Анимация частиц: canvas; пауза, когда вкладка скрыта; выключена в «Экономии трафика» и при `prefers-reduced-motion` (статичный фон).
3. Бюджет JS страницы ≤ 500 КБ; экраны загружаются по требованию; Lighthouse не хуже текущих страниц химии.
4. Доступность: axe без serious/critical, клавиатура, видимый фокус, подписи для диктора. Исправления доступности — только невидимые или минимальные, без изменения дизайна. Где без видимого изменения не обойтись — показать владельцу.
5. Права: тест, квиз и ИИ — только после входа; гостю — экран входа платформы. Учитель видит атлас в режиме предпросмотра.
6. Ключ DeepSeek, `secrets.js`, `api/chat.py`, `netlify/` не попадают в репозиторий; поиск по истории коммитов задачи — в отчёт.

### REQ-ATL-07. Что из CHEM_TZ сохраняется
- Темы, вопросы, глоссарий, лента, переводы и все исправления содержания.
- Общие функции платформы (главы, глоссарий, лента, таблица) остаются в коде для других предметов; для химии их стандартный вид не показывается.
